# Findings

- 2026-08-31 — **Authoritative interception surface** — Codex `SubagentStart` cannot block a child launch; it can only add context and record lifecycle evidence. Both Claude and Codex expose provider-native delegation requests through `PreToolUse`, so the enforcement point is the shared Aegis PreToolUse dispatcher. `SubagentStart` remains passive and must not be represented as the security boundary.
- 2026-08-31 — **Managed-context authority** — A repository is managed when its canonical Git root resolves through a strict `.gas-city-workflow.json` descriptor, the source-root `plugins/gas-city-workflow/config/projects.json` registry, or both with exact semantic agreement. Malformed identity, descriptor/registry disagreement, or an invalid canonical/worktree relationship fails closed for provider-native delegation. An unregistered repository remains unaffected.
- 2026-08-31 — **Provider-native work surface** — Creating or resuming delegated provider work is blocked for Claude `Agent`/`Task` and Codex `spawn_agent`/`assign_agent_task`/`followup_task`/`resume_agent` (including normalized collaboration-qualified names). Observation, waiting, interruption, containment, and coordinator-local tool use remain available.
- 2026-08-31 — **Reviewed exception contract** — The only exception is an optional tracked, clean, HEAD-bound `.gas-city-delegation-exceptions.json` record matching project, adapter, normalized tool, exact request digest, exact branch, bead, and review evidence. The complete file must also be byte-identical on the project's canonical reviewed base (`base_ref` or `origin/main`), so an arbitrary unmerged origin-tracking ref cannot authorize delegation. Authorization never depends on caller, session, agent identity, advisory mode, or a failed Gas City route. Exact exceptions are explicitly recorded; all mismatches deny.
- 2026-08-31 — **Non-interference** — The repair changes source and generated installer definitions only. It does not install into HPFetcher or touch its active beads, worktrees, sessions, reports, or rig lifecycle while Fable's protected lane is active.
